# AHANGBAZAR

A modern bilingual (English / فارسی) music streaming web application built with **Next.js**, **React**, and the Web Audio API.

---

## Features

- 🎵 Full music player (play / pause / next / previous / seek)
- 🔀 Shuffle & Repeat modes
- 🔊 Volume control + mute (RTL-aware)
- ❤️ Favorites (persisted in `localStorage`)
- 🔍 Real-time search (title, artist, Persian names)
- 🔗 Share tracks (Telegram, WhatsApp, native share, copy link)
- ⬇️ Download tracks
- 🌙 Light / Dark theme (Ivory / Obsidian)
- 🇮🇷 Full RTL support + Persian translations
- ⌨️ Keyboard shortcuts (`⌘K` / `Ctrl+K` for search, `Esc` to close modals)
- 📱 Responsive design (mobile bottom nav + desktop sidebar)
